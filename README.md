# 公開データについて
このリポジトリでは、近世マニラで刊行された中国キリスト教文献『新刊格物窮理便覽』のTEI/XMLデータを順次公開しています。
# ビューワについて
公開データは[こちらのビューワ](https://www.flxstyle.com/teiviewer4eaj/manila/?file=https://raw.githubusercontent.com/WWenlu/manila-simbolo/refs/heads/main/Gewu_qiongli_bianlan_20260904_vol.1.xml)からご覧いただけます。ビューワに関しては、一般財団法人人文情報学研究所が公開している[TEI古典籍ビューワ](https://tei.dhii.jp/teiviewer4eaj)を基礎として、『新刊格物窮理便覽』表示のためのカスタマイズをフェリックス・スタイルの本間淳氏が行いました。
# 謝辞
本研究データは、日本学術振興会科研プロジェクト[近世カトリック宣教文献の横断的比較：マニラ刊漢訳教理書『格物窮理便覧』を中心に（20K21921）](https://kaken.nii.ac.jp/grant/KAKENHI-PROJECT-20K21921)、[TEIを中心とした高度な歴史テキスト構築（25H01244）](https://kaken.nii.ac.jp/grant/KAKENHI-PLANNED-25H01244)、[フィリピンに消えたキリシタン：近世スペイン領マニラにおける日欧華文化交流の諸相（26K00181）](https://kaken.nii.ac.jp/grant/KAKENHI-PROJECT-26K00181)の成果です。
