# プロジェクト概要
「『新刊格物窮理便覧』デジタル校訂本プロジェクト」は、1607年にフィリピン・マニラで刊行された漢文キリスト教文献『新刊格物窮理便覧』（以下『格物』）を対象に、翻刻テキストの作成とTEI/XMLによる構造化を行い、原資料画像とあわせて閲覧可能なデジタルテキストとして公開することを目的とするプロジェクトです。現在、第1巻のデータを公開しており、第2巻・第3巻についても順次整備・公開する予定です。
『格物』は、ドミニコ会士トマス・マヨール（Thomas Mayor, OP）によって編纂された、フィリピン初期漢文刊本を代表する文献の一つです。全三巻、約14万字に及ぶ大部の著作であり、キリスト教教理のみならず、自然学、霊魂論、天地創造、中国の宗教・文化に対する認識など、多岐にわたる内容を含んでいます。
現在、『格物』には、オーストリア国立図書館本（Sin. 267）、ローマ・イエズス会文書館本（Jap. Sin. I, 171）、ライデン大学図書館本（21.591 G）、ロシア国立図書館本（ОP, Дорн700）の四伝本が知られています。なかでも、オーストリア国立図書館本は初刻本と考えられています。
近年、各所蔵機関によるデジタル画像の公開や影印本の刊行によって、『格物』へのアクセス環境は大きく改善しました。一方で、長大な段落、閩南語による音訳語、多数の異体字・俗字、複雑な版面などのため、本文を直接検索・比較・分析することには、なお一定の困難があります。
本プロジェクトでは、オーストリア国立図書館本を中心にデジタルテキストの整備を進め、翻刻本文にTEI/XMLマークアップを施すことによって、本文の可読性・検索性を高めるとともに、今後の文献研究・比較研究の基盤となるデータの構築を目指しています。
# 公開データについて
このリポジトリでは、本プロジェクトが作成した『新刊格物窮理便覧』のTEI/XMLデータを順次公開してまいります。公開データは、TEI古典籍ビューワを利用した閲覧環境から、本文と原資料画像を並行して参照することができます。また、本文中の文書構造、音訳語、人名・地名、西洋語原語などを視覚的に確認できるようにしています。

公開データは[こちらのビューワ](https://www.flxstyle.com/teiviewer4eaj/manila/?file=https://raw.githubusercontent.com/WWenlu/manila-simbolo/refs/heads/main/Gewu_qiongli_bianlan_20260904_vol.1.xml)からご覧いただけます。ビューワに関しては、一般財団法人人文情報学研究所が公開している[TEI古典籍ビューワ](https://tei.dhii.jp/teiviewer4eaj)を基礎として、『新刊格物窮理便覽』表示のためのカスタマイズをフェリックス・スタイルの本間淳氏が行いました。
